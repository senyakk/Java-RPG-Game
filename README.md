# Java RPG Game 🛡️

A compact 2D RPG (Role‑Playing Game) built in Java — featuring simple inventory, map exploration, and basic NPC AI.
 
- **Explorative world**: multiple rooms/zones to navigate  
- **Inventory system**: collect and equip items such as weapons and consumables  
- Easily extendable: add new weapons, enemies, levels
